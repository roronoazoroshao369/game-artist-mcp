# Held-out brief — Astral Root Compass / Linh Căn Bàn

Design one ORIGINAL portable compass relic for a lone cultivation-survival traveler. Circular weathered bronze frame, cracked dark stone dial, a visibly off-center jade-cyan pointing needle, a small brass loop for attaching to a rope and one asymmetrical red-cord tassel. Emphasize a strong readable silhouette at 64 px, handmade irregularity, clearly distinct bronze/stone/spirit materials and a sparse original symbol language. A single asset centered on a transparent 192 × 256 canvas, with no words, branding, intellectual-property borrowing, generative models, hardcoded object templates or reference coordinate recipes. The artist must create editable geometry with MCP tools, inspect a real first PNG and revise the same document based on visible flaws.
