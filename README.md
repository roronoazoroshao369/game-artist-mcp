# Game Artist MCP

An AI-native, deterministic game-art workstation for agent hosts.

## Current scope

POC-001 proves the smallest useful loop:

```
structured art document
→ typed deterministic operations
→ SVG render
→ PNG preview
→ validation
→ reproducible output
```

The project intentionally starts with 2D stylized/cutout-friendly art. It does **not** use a generative image model as the core asset engine.

## Status

Early proof of concept. Do not treat current output quality or APIs as production-ready yet.
